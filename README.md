## Featured Projects

### 🔵 [5G NR PDSCH Simulator](https://github.com/Ahmedaltu/5g-nr-pdsch-simulator) `MATLAB`
Full physical-layer link-level simulator for 5G NR downlink. Implements LDPC coding, OFDM modulation, PDSCH resource mapping, and AWGN/fading channel models. Outputs BER/BLER curves against SNR.

### 🟣 [Wireless Signal Processing — MATLAB](https://github.com/Ahmedaltu/wireless-signal-processing-matlab) `MATLAB`
RTL-SDR workflows covering FM/RDS demodulation, LRPT satellite decoding, MUSIC/ESPRIT array signal processing, multirate filtering, synchronization algorithms, and ML-assisted receivers.

### 🟢 [ML Wireless Localization — Channel Charting](https://github.com/Ahmedaltu/ml-wireless-localization-channel-charting) `Python`
Self-supervised radio localization using channel charting — learns a geometry-preserving map of UE positions from CSI measurements without ground truth labels.

### 🔴 [Metal3 Kubernetes Lab](https://github.com/Ahmedaltu/metal3-kubernetes-lab) `Shell`
Reproducible lab deploying bare-metal Kubernetes clusters with Metal3 (Cluster API provider). Covers IPMI/BMC provisioning, Ironic, and full lifecycle management.

### 🟡 [Istio Service Mesh Lab](https://github.com/Ahmedaltu/istio-service-mesh-lab) `Shell`
End-to-end Istio setup: mTLS, traffic shifting, fault injection, Kiali observability, and Envoy proxy configuration — structured as a reproducible learning environment.

### 🟠 [Ubuntu Cloud Lab](https://github.com/Ahmedaltu/ubuntu-cloud-lab) `Python`
GCP Ubuntu 24.04 lab covering: `netcheck` Python CLI, `dpkg-deb` packaging, cloud-init user-data automation, and systemd service deployment.

### ⚪ [WireGuard VPN Lab](https://github.com/Ahmedaltu/wireguard-vpn-lab)
Self-hosted WireGuard VPN on Oracle Cloud free tier — peer configuration, key management, routing, and automated setup scripts.

### 🟤 [Distance Measurement via BLE](https://github.com/Ahmedaltu/Distance_Measurement_Bluetooth) `C`
nRF52840-based indoor distance measurement using Bluetooth Low Energy RSSI. Zephyr RTOS, custom BLE profiles, and Python post-processing.

### ⬛ [Green House FreeRTOS](https://github.com/Ahmedaltu/Green_House_FreeRTOS)
Industrial greenhouse CO₂ controller on LPC1549 (ARM Cortex-M3). FreeRTOS task scheduling, Vaisala GMP252/HMP60 sensors, Modbus RTU, ESP8266 WiFi/MQTT bridge, and 16×2 LCD UI.

### 🔵 [TrackLight — UWB Spotlight](https://github.com/Ahmedaltu/TrackLight) `C++`
ESP32-based automotive spotlight that tracks a user using UWB positioning. Real-time angle-of-arrival estimation driving servo-controlled beam steering.

### 🟢 [Nettiauto Financing Analyser](https://github.com/Ahmedaltu/Nettiauto-Financing-Analyser) `JavaScript`
Chrome extension that overlays financing cost analysis on Nettiauto listings — calculates total cost of ownership, monthly payment breakdown, and interest burden.
